# Verifiable Credential Wallet PWA (UIDAI Sandbox assignment)
React + Vite. State: Context API + useReducer. Tests: Vitest + React Testing Library (Jest-compatible API).

    npm install
    npm run dev      # http://localhost:5173
    npm test         # SecureDataMask timer test

Try UI states: `/?fail` (error) and `/?empty` (empty).
Service worker: `public/sw.js` (build with `npm run build && npm run preview`, then DevTools > Network > Offline).
